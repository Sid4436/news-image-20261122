One image summing up the world's news of **Sunday, 22 November 2026**:
COP31's final draft in Antalya, Iran's strike on Bahrain and the tankers
hit near the Strait of Hormuz, the capture of cartel boss "El Chapo
Isidro" in Sinaloa, the Russian ship Sparta II ablaze in the Gulf of
Finland, Verstappen's win at the Las Vegas Grand Prix, and the funeral
boat that capsized in Bayelsa, Nigeria.

`main.ts` (Node 22, standard library only) copies the pre-rendered
`entry.png` to `MAKEFUN_OUTPUT_DIR` (default `/output`). Both runs write
byte-identical output. No network is used.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

Entry for the [make.fun](https://make.fun/c/news-image-20261122)
competition "Sum up 22 November's world news in one image".
